How text is extracted

  1. Spreadsheet check. If every line has the same number of tabs (a copy from Excel or Sheets), each line becomes a row and the rules below are not used.
  2. Split into records. The text is cut into records (see Records & rows). Each record can produce one or more rows.
  3. Run the rules, top to bottom: Key: Value lines, then your custom rules, then the built-in rules. Each rule's matches go into its column. A built-in rule claims the text it matched, so a later rule can't use it again (digits inside a date never become a phone number).
  4. Build rows. If a column found several values in one record, each value gets its own row; or they're joined into one cell.
  5. Filter. Rows missing a required column are dropped, and rows already in the table are skipped.

All rules are saved automatically in this browser and used by the table right away. Every saved project file also contains a copy of the rules it was made with.

Extraction rules

Each rule is a regular expression. The count shows how many values it finds in the test text. Use a capture group to keep only part of a match, e.g. Order #(\d+) with group 1 keeps just the number.
